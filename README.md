Este projeto foi desenvolvido como parte da disciplina de Mobile Coding, com o objetivo de aplicar os conhecimentos adquiridos sobre desenvolvimento de interfaces em Flutter. A proposta consiste na criação de uma tela de agendamento de serviços para uma barbearia fictícia chamada "Outback Cortes".
A interface foi baseada em um protótipo criado no Figma, buscando uma identidade visual personalizada, com cores marcantes e tipografia temática. A principal funcionalidade da tela é permitir o cadastro de um agendamento, contendo campos como nome do cliente, serviço desejado, data e horário, além de uma opção para notificar o cliente por e-mail.
